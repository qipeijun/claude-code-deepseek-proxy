Problem & Solution

为什么要用这个代理？

直接用 DeepSeek 接 Claude Code 会遇到两个致命问题——这个代理把它们都解决了。

⚠️
子代理请求被拒
Claude Code 子代理同时携带 thinking: { type: "disabled" } 和 reasoning_effort: "medium"。DeepSeek 严格校验，认为关了思考就不能设 effort，直接返回 400。所有子代理和并行 agent 全部不可用。
→ 本代理在发出前自动清洗矛盾字段
🔄
模型名对不上
Claude Code 用 claude-sonnet-4-6 发过去，上游返回 deepseek-v4-pro。Claude Code 根据响应模型名做后续决策，如果不对会导致行为异常甚至功能不可用。
→ 请求替换 + 响应还原，SSE 流逐事件改写
↓
Features

核心能力

不只是转发——在请求链路的关键节点做精确处理。

🧹
请求体规范化
检测并清洗子代理请求中 thinking / reasoning_effort 的冲突组合，主代理扩展思考不受影响。
关键
🔄
模型名改写
请求替换为上游模型名，响应（JSON + SSE 流）还原为原始模型名。SSE 做事件边界缓冲，避免跨 chunk 截断。
🔀
智能路由
exact 精确匹配优先于 prefix 前缀匹配，多个命中取最长前缀。无匹配返回 Anthropic 格式 404。
🛡️
Fallback 容灾
显式配置的 fallback 链，5xx/429/异常触发切换，按序尝试。不做静默降级，不自动兜底。
✅
内容块校验
发出前遍历 system 和 messages[].content，对比 provider 能力声明，不支持的类型返回明确错误。
🔌
连接池管理
undici Agent 按 origin 缓存复用，槽位机制控制并发（默认 32），池满返回 503，≥80% 预警。
📊
实时指标
内存环形缓冲区记录最近 200 条请求。延迟分布（P50/P95/P99）、吞吐量、Token 统计、连接池使用率。
⚙️
可视化配置
Web 管理后台，三步配置向导，方案 CRUD，上游模型查询，连通性测试，无需手动编辑配置文件。
Get Started

快速开始

不需要 .env 文件。克隆、安装、启动，然后在管理后台完成配置。

1. 克隆并启动代理

首次启动无配置，终端会打印 banner 并提示打开管理后台。

$ git clone https://github.com/qipeijun/claude-code-deepseek-proxy.git
$ cd claude-code-deepseek-proxy
$ npm install && npm start

STEP 2

打开管理后台，三步完成配置

① 填写上游地址 + API Key，获取模型列表验证连通性

② 添加路由规则（一键添加 Sonnet/Opus/Haiku）

③ 设为当前并保存，重启服务

http://127.0.0.1:8787/admin
STEP 3

配置 Claude Code 客户端

设置 Anthropic 的 Base URL 指向本代理。如果在 admin 中设置了鉴权密码，也需配上。

export ANTHROPIC_BASE_URL="http://127.0.0.1:8787" # 若设置了鉴权密码：export ANTHROPIC_API_KEY="你的密码"

直连 DeepSeek 经 New API 网关

适用场景个人开发，追求最低延迟团队共享、用量管理和计费控制
API Reference

API 端点

代理兼容 Anthropic Messages API，并提供配置管理和监控端点。

方法 路径 说明
POST /v1/messages Anthropic Messages API，支持 SSE 流式响应
POST /v1/messages/count_tokens Token 计数
GET /v1/models 列出当前路由覆盖的模型
GET /healthz 健康检查
GET /admin 管理后台页面
GET /api/admin/profiles 列出所有配置方案
POST /api/admin/profiles 创建配置方案

DELETE /api/admin/profiles/:id 删除配置方案
POST /api/admin/profiles/activate 激活配置方案（重启生效）
POST /api/admin/upstream-models 查询上游可用模型列表
GET /api/admin/metrics 获取实时性能指标
